**Context.** This PR converts every public component value prop from
`Option<RwSignal<T>>` (or required `RwSignal<T>`) to `Option<ReadSignal<T>>`
with a component-owned internal echo signal (`echo_signal` helper,
`src/utils/echo_back.rs`) and intent callbacks out. The core invariants:
(1) components never write external/parent state; (2) external changes sync
inward (guarded against echo loops); (3) user intents fire callbacks;
(4) uncontrolled usage (no prop passed) behaves exactly as before.

## Claims to attack (verify each against the code, cite file:line)

1. **Census completeness.** After this diff, NO public component prop in
   `src/components/` accepts a writable `RwSignal` value. Remaining
   `RwSignal` occurrences are exclusively: component-internal state
   (`menu.rs` opened, `notification.rs` store, `symbol_palette.rs`
   active_category, `coordinate_input.rs` coord_inputs,
   `tensor_input.rs` slice_indices, `matrix_input.rs` focused_cell) and
   internal context plumbing (`provide_context`/`use_context` of the
   provider's own internal signal in popover/tabs/menu). Verify by grep and
   by reading each hit.
2. **echo_signal semantics.** `src/utils/echo_back.rs`: seeds untracked from
   external-when-Some else default; installs an Effect that propagates
   external→internal only when values differ (no redundant write, hence no
   parent→child→parent loop through this helper alone); never writes
   external; no-op when external is None. The 5 tests actually cover:
   seed-from-external, seed-from-default, inward propagation, equality
   guard, uncontrolled writability.
3. **No external writes anywhere in converted components.** For each of the
   22 converted components, every `.set(`/`.update(` on the value path
   targets the internal echo signal, never a prop. Special cases:
   `PopoverTarget` and `TabsTab` write the signal obtained from
   `use_context` — verify the provider (`Popover`, `Tabs`) provides its
   INTERNAL echo signal, not any external prop.
4. **Callback firing paths.** Switch/Checkbox/Radio fire `on_change` on the
   user-action path (pre-existing); Popover fires its NEW `on_change(bool)`

   TableWithPagination's pagination callback fires the NEW `on_page_change`

   semantics. The 10 scientific components fire their pre-existing
